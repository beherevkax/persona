# CLAUDE.md

Этот файл содержит рекомендации для Claude Code (claude.ai/code) при работе с кодом в этом репозитории.

## Обзор проекта

Persona — одностраничное персональное портфолио на русском языке. `index.html` представляет собой готовый к развёртыванию сайт: семантический HTML, встроенные CSS и SVG-графика, без JavaScript и внешних зависимостей во время выполнения.

Перед изменением дизайна или содержимого прочитайте `111.md` — это описание проекта. `profile.md` содержит подробные сведения о владельце, а `про-меня.md`, `проекты.md` и `факты.md` — краткую биографическую справку, описание опыта и навыков. Эти Markdown-файлы не обрабатываются и не загружаются сайтом. Видимый текст хранится непосредственно в `index.html`, поэтому изменение справочного Markdown-файла не обновляет страницу.

В каталоге `images/` находятся локальные ресурсы, сведения о лицензиях на которые приведены в `images/CREDITS.md`; текущая версия `index.html` не использует их.

## Команды

Выполняйте команды из корневого каталога проекта.

```powershell
# Открыть сайт в браузере по умолчанию.
Start-Process .\index.html

# При необходимости запустить локальный HTTP-сервер (требуется Python),
# затем открыть http://localhost:8000/.
py -m http.server 8000
```

Этап сборки отсутствует: для развёртывания достаточно раздавать каталог проекта как статические файлы. Линтеры, автоматические тесты, средство запуска тестов и команда для запуска отдельного теста не настроены. Проверяйте изменения в браузере, включая навигационные ссылки и адаптивную вёрстку.

## Архитектура и оформление

- Сайт должен оставаться одним автономным файлом `index.html` со встроенным CSS. Не добавляйте фреймворки, пакетные менеджеры, средства сборки, внешние зависимости или излишне сложную архитектуру.
- Глобальные цвета и типографика заданы пользовательскими свойствами CSS в блоке `:root`. Для раскладки используются CSS Grid и Flexbox; адаптивные контрольные точки — 900 и 620 пикселей. После изменения раскладки проверяйте сайт на настольных компьютерах, планшетах и узких мобильных экранах.
- Навигация в шапке и внутристраничные ссылки используют идентификаторы `top`, `about`, `work`, `skills` и `contact`. При перестройке разделов сохраняйте эти цели и связанные с ними атрибуты `aria-labelledby`.
- Существующие меры обеспечения доступности включают семантические ориентиры, видимый индикатор фокуса при навигации с клавиатуры, скрытие декоративных SVG от вспомогательных технологий и правило `prefers-reduced-motion`. При изменении этих элементов сохраняйте аналогичное поведение.

## Рекомендации по содержимому и дизайну

- Видимые тексты должны быть на русском языке, от первого лица, простыми, дружелюбными и конкретными. Избегайте канцелярита и искусственно официальных формулировок.
- Биографические сведения берите из справочных Markdown-файлов; не выдумывайте опыт или навыки.
- Предпочитайте креативное, персональное визуальное оформление типовому шаблону портфолио, но не жертвуйте ради визуальных эффектов читаемостью, удобством, адаптивностью и простотой.

## Лицензирование изображений

При использовании или замене файлов в `images/` поддерживайте `images/CREDITS.md` в актуальном состоянии. При публикации изображений под лицензиями CC BY и CC BY-SA необходимо указывать автора и лицензию; используйте сведения об источнике и лицензии, приведённые для каждого файла.
