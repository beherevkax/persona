# Инфраструктура и личный инструментарий

Держу собственный Linux VPS с Hermes Agent по имени «Джарвис» — управляю им через Telegram, команды часто отправляю голосом. В Telegram подписан как Павел. Для Hermes предпочитаю GPT Sol через подписку OpenAI Codex с OAuth, без отдельной оплаты за токены по API — от платного API-доступа отказался.

Сервер и VPN — мои собственные. На iPhone использую V2Box (раньше пробовал Happ и Streisand), на Windows — Chrome через SSH-прокси. Это split-tunneling: ИИ-сервисы маршрутизируются через VPN точечно, без заворачивания туда всего трафика.

Веду базу знаний в Obsidian, синхронизирую её между Windows и iPhone через iCloud и Git. Пользуюсь локальной диктовкой речь-в-текст на ПК и iPhone (Spokenly, LocalWhisper), через Apple Shortcuts настроил отправку голосовых заметок в Telegram-бота.
